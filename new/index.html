--- layout: default title: New entry description: Post a new entry. permalink: /new/ sitemap: false noindex: true csp: true --- {% comment %} new/index.html — the one-page "post from my phone" screen. The flow, one step at a time on the same page: 1. "What are you reading?" Tap the book. Books marked "reading" are big buttons at the top, because that's almost always the answer. 2. Not there? "Something else" shows every other log, plus "Start a new one", which asks for title, author/studio and type. 3. Write: chapter (filled in with the last chapter you logged), the text, and Post. GitHub's "new file" screen opens with it all filled in, and you tap "Commit changes". The site updates a minute or two later. Why GitHub's screen does the saving: this page holds no keys or passwords at all, on purpose. Saving uses the GitHub login you already have. A stranger who finds this page can't post: GitHub won't let them commit. (A version that saved straight from this page with a stored key was built and then removed; the reasons are at the top of assets/js/new-entry.js.) sitemap: false and noindex: true keep this page out of search engines. It's a tool, not a page to read. csp: true switches on a strict safety rule for the browser (written in head.html, called a Content-Security-Policy). On this page, scripts may only come from this site, and the page can't send data anywhere at all. So even if something sneaky got onto the page, it couldn't send your drafts off. {% endcomment %} {% comment %} Everything the page needs to know about the logs, handed to the JavaScript as data. type="application/json" means the browser never runs it; the script just reads it. That matters because the safety rule above blocks scripts written inside the page. For each log we also include the last chapter and a short bit of the last entry, so the write step can say "Last time: Ch 17, 'Nesta is still…'" and fill in the chapter for you. {% endcomment %} {% comment %} The data is built first, then every "" would otherwise end this block early and break the page.
